# SysV Common V2 migration

Independent read-only System V Release 2 and Release 4 candidate.
Supports conventional clean superblocks at byte 512, both byte orders,
512/1024/2048-byte filesystem blocks, complete bounded free-list walk,
14-byte names, nested directories, sparse regular files, direct and
single/double/triple indirect addressing and link metadata. The hosted
and AMD64 firmware builds share one source and carrier.

The byte-authored tests do not constitute independent vintage media
qualification. Xenix, Coherent, V7, SCO EAFS, nonstandard placements,
dirty volumes, full allocation ownership verification, formatting,
mutation, defragmentation and release remain outstanding.
